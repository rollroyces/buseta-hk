# Architecture

High-level overview of BusETA HK. For deep details on a subsystem, see the linked docs.

## What it is

A single-page web app showing real-time Hong Kong transit arrivals across KMB / LWB / Citybus / NWFB / GMB / MTR / Light Rail. Mobile-first, bilingual (繁體中文 / English), zero build step, ~75 KB before first paint.

## Routing

Hash routing (`#/...`). The router is a switch on `state.view` driven by `window.location.hash` change events. Routes:

- `#/` — home (saved routes, recent, nearby)
- `#/search` — search tab (KMB / CTB / GMB / MTR / LRT)
- `#/route/<co>/<route>` — route detail (e.g. `#/route/KMB/970`)
- `#/stop/<id>` — bus stop detail (e.g. `#/stop/MA973`, `#/stop/210680`)
- `#/station/<id>` — MTR station (e.g. `#/station/HOM`)
- `#/lrt-stop/<id>` — LRT stop detail
- `#/gmb-stop/<id>` — GMB stop detail
- `#/planner` — trip planner

KMB operator-facing codes (e.g. `MA973`) are resolved to internal 16-hex IDs (`210680...`) at render time via the `kmbOperatorId` reverse map, then carried through `stateRef.internalStopId` to all downstream fetches (v36).

## State management

Single in-memory `state` object. Three persistence layers:

| Layer | Used for |
| --- | --- |
| `localStorage` | saved routes / stops / stations, recent searches, onboarded flag |
| Service Worker cache | static assets (immutable), data assets (cache-first), upstream API responses (SWR) |
| `state.index` | in-memory index built from `assets/*-stops.json`; rebuilt on `INDEX_SCHEMA_VERSION` bump |

## Versioning

| Where | What | When |
| --- | --- | --- |
| `index.html` `<meta name="buseta-version">` | App-facing version | Bumped on every user-visible change |
| `sw.js` `const CACHE = 'buseta-vNN'` | Service-worker cache bucket | Bumped in lock-step with `buseta-version` to force clean installs on existing users |
| `index.html` `<script>` `?v=NN` | JS / CSS cache-busters | Bumped when the underlying file changes |
| `app.js` `INDEX_SCHEMA_VERSION` | Shape of `state.index` | Bumped when the index schema changes — old indexes are discarded and rebuilt |
| `package.json` `devDependencies` | Tooling versions | Updated by Dependabot (weekly, Mon 09:00 HKT) |

## Build / deploy

- **No build step.** Source ships as-is.
- `planner.min.js` and `planner.min.css` are pre-minified siblings of the source files. Regenerated by the maintainer via `.minify/minify.py` (not in repo).
- **GitHub Pages** auto-deploys from `main`.
- **Verification** (per maintainer's commit messages): `tree-sitter` parse-check + `curl` against `rollroyces.github.io/buseta-hk/` after each push.
