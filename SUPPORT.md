# Support

## How to get help

- **Bug?** Open an [issue](../../issues/new/choose) using the bug-report template.
- **Feature idea?** Open an [issue](../../issues/new/choose) using the feature-request template.
- **Question?** Check the [README](./README.md) first — most features are documented. If the README doesn't answer it, open an issue with the question and we'll point you to the right docs.

## What's in scope

BusETA HK supports the following transit operators in Hong Kong:

- KMB (九巴) — Kowloon Motor Bus
- LWB (龍運) — Long Win Bus
- Citybus (城巴)
- NWFB (新巴) — New World First Bus
- GMB (專線小巴) — Green minibus
- MTR (港鐵) — Heavy rail
- Light Rail (輕鐵)

For services NOT covered (e.g. tram, peak tram, ferry, MTR Bus), we suggest using the operator's official app or website.

## What we can't help with

- **Lost items on a bus / minibus / MTR** — contact the operator's lost-and-found directly.
- **Refunds / fare disputes** — contact the operator's customer service.
- **Real-time service status outside the app** — BusETA HK reflects upstream data; if KMB / CTB / MTR are showing wrong data upstream, we can't fix it (but please open an issue so we can route it correctly).
- **Tram / Peak Tram / Star Ferry / MTR Bus / etc.** — out of scope for this app.

## Reporting a vulnerability

If you found a security issue, see [SECURITY.md](./SECURITY.md) for the private disclosure process. **Do not** open a public issue for security problems.
